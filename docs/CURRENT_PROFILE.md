# 简体中文版与恢复修复

版本 `0.0.27-zh-cn.1`（28），包名 `io.github.jqssun.displayextend`；分支 `codex/zh-cn-localization`。基线上游 v0.0.27 / `4598db3f710a7d7081c4386c5353d909f573ed10`。

## 修改

- 默认英文保持，新增 213 条简体中文资源，涵盖概览、显示配置、设置、权限/无障碍说明、触控板、错误、对话框、日志操作和通知。
- MediaProjection 的渠道、标题和后台通知文字外置为资源，悬浮返回按钮增加可本地化的无障碍描述。系统 API、flag、包名、外部应用名及原始调试日志保留原文。
- 任意副屏被移除时，如本应用的黑屏界面仍打开，主动请求恢复手机面板并关闭该界面。采用较保守的恢复时机，兼顾物理宿主消失而托管虚拟显示仍存活的情况；不销毁托管应用会话。
- ExitAll 在 killProcess 前显式恢复内屏，避免依赖可能不会执行的 onDestroy。恢复步骤先请求面板开启，再停止音量键监听并退出黑屏；一个 IPC 步骤失败时仍尝试后续步骤。
- `ScreenRecovery` 只是步骤隔离，不改变底层电源 API。Shizuku binder 不可用或固件拒绝请求时，不能保证实际面板已恢复；软件测试不证明硬件行为。
- 不依赖 HyperDesktopUnlock 私有接口，不新增权限，不修改构建系统版本。

## 高权限边界

- Shizuku 经用户授权后可用 shell/root 身份控制显示和输入。上游设置页会尝试授予本包 WRITE_SECURE_SETTINGS；已同意无障碍披露后，程序可写本包无障碍服务的系统启用条目。
- 真正关内屏默认关闭。音量键底层 getevent 恢复依赖 root/设备权限；无线调试启动的 shell Shizuku 不能据此假定可用。先用黑屏模拟模式测试，再由用户决定是否启用真实关屏。
- 日志导出读取系统 logcat，分享前应检查内容。FileProvider 对应用缓存共享明确授权 URI；无网络上传接口。导出的 ExitReceiver 只允许结束黑屏，可能被其他应用调用，未将其改为可能破坏 shell/root 兼容性的未经验证权限方案。
- 不启用已知可能导致 HyperOS SystemUI 崩溃的 freeform/强制多窗口开关。单屏 DPI、分辨率、刷新率、旋转和 IME policy 由本应用管理，Unlock 精简版不再竞争这些配置。

## 手动安装、升级和回退

安装前记录原版版本和设置；不同签名不能原位覆盖，同包名卸载会清除本应用设置。只在内屏已恢复、外屏断开、显示/输入会话已退出后处理卸载或签名切换。相同 debug 证书且版本码不降低时可以更新安装，但不要把本机构建当成上游签名版本。

安装后按需授予 Shizuku、悬浮窗、通知及无障碍权限，首次不启用自动关屏或托管模式。选择物理外屏启动一个普通应用，验证触控板/键鼠、返回和应用切换，再逐项设置外屏原生比例与 DPI。

回退前恢复内屏，停止触控板/悬浮按钮/托管显示，按需用显示详情的重置配置恢复覆盖；全局 USB 音频与内容帧率设置应单独核对。用 Unlock 或系统入口恢复镜像后断线。随后卸载或换回保留的原签名 APK，重新授予必要权限。

如果关屏后无法控制手机，先尝试已验证的音量恢复路径，再用电源键锁定/唤醒手机；Shizuku 丢失时应先恢复服务再重试。此处是待实测的恢复路径，不代表已在目标手机验证。本次未操作任何设备。
